# 发现选品机会

目的不是列增长榜，而是找到需求可验证、供给有缺口、卖家能进入的机会。无参数做全周期全类目初筛；参数指定方向时先映射并验证实际命中，仅在该范围筛选。

1. 利用已有概览，以 category_analysis 找购买需求与集中度差异。search_keywords 对比 purchases、low_concentration、low_title_density 三个筛选角度；缺失指标单独标记，不当成优势。
2. 从命中词中选少量不同需求簇，用 keyword_analysis/keyword_history 检查需求持续、购买承接、头部点击与转化份额。低标题密度只代表样本标题覆盖，不能断言供应不足。
3. keyword_asins 查看真实 TOP10 的价格、评分评论、变体与卖家结构；选 1–3 个 ASIN 用 product_history/asin_trends 检查价格战、销量、BSR 与成熟度。用 google_trends 对关键候选辨别外部季节性。
4. 形成“需求信号—供给缺口—可做差异—主要反证—验证门槛”的候选链。明确淘汰至少一种看似增长却缺乏承接或已被头部锁定的方向；证据无合适候选时直接说明。

交付少量有顺序的候选、入选依据、放弃理由和最低成本验证任务。按证据强弱解释顺序，不创建没有透明依据的综合分或成功率；成本、评论文本或供应链能力未知时列待验证，不承诺利润。
