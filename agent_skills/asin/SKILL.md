# ASIN 竞品研究

无参数依据全周期全类目选代表商品；有 ASIN 按完整 10 位字母数字识别并转大写，标题/品牌/方向先 search_asins 定位。ASIN 未存商品档案仍可检索自然位和 TOP3 快照，不立即断言不存在。

1. asin_analysis 建立 1–3 个对象的关联词、档案和月度趋势；product_history 检查实际 fetched_at、价格、BSR、评分评论、上架、变体、FBA 与卖家字段。
2. asin_trends 核对销量、价格、销售额和 BSR 变化及数据来源。价格下降与销量上升只是共变，不能直接断言广告促销导致；BSR 是类目内排名，跨类目不可比较。
3. 选关联词用 keyword_snapshots/keyword_analysis 查看头部位置和份额，解释流量依赖、核心需求与竞争稳定性。只在证据允许时与同需求竞品比较。

交付商品定位、核心流量、时间变化、优势/脆弱点、差异化假设及待补字段。评论数、LQS 或缓存毛利率不是真实用户诉求、平台推荐权重或最终净利润；没有评论正文不编造评论洞察。
