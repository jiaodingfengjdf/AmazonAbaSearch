# 竞争格局研究

无参数从全周期全类目比较竞争结构；参数把分析约束到真实关联词与竞品。品牌、卖家、父子变体和单 ASIN 是不同实体，不把重复变体算成独立竞争者。

1. category_analysis/search_keywords 识别集中与分散的需求簇；keyword_snapshots/keyword_analysis 检查 TOP3 品牌和点击、转化份额的多期稳定性。
2. keyword_asins 对代表词读取 TOP10 完整商品，结合 search_asins/product_history 描述价带、评论成熟度、产品形态、变体和卖家结构。样本价带不能冒称整个类目价格分布。
3. asin_trends 验证降价、销量/BSR 和评论积累变化；对“容易进入”的候选主动找头部品牌锁定、价格压缩、长尾需求小或评论壁垒的反证。

输出竞争结构、进入门槛、可差异化假设与验证条件。低 TOP3 集中度并不代表低竞争；头部集中也不等于已证明垄断。无全市场份额与合规证据，不作法律垄断结论。
