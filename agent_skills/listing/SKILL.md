# Listing 内容研究

无参数从全周期全类目形成代表需求的内容研究，不凭空为不存在的商品写认证或功能。参数指定对象后先建立真实意图与产品事实表。

1. search_keywords/keyword_analysis 对核心、属性、场景与品牌词分组；keyword_asins/product_history 读取现有标题与商品字段。标题密度可帮助理解样本覆盖，不能当确定排名算法。
2. 有附件用 list_attachments/search_attachments/read_attachment 读取原文规格；直接观察已附图片的可见构图、可读文字、使用表达，区分可见事实与推测。图片不能证明材质、安全性、尺寸精度或认证有效。
3. 建立“需求—产品证据—内容位置—待补证明”映射，再提出标题、要点、描述或图片信息结构。已有证据支持才能写具体规格、适配性和性能；医疗、安全、环保和对比优越声明需核实，不虚构证明或评论。
4. 现行字符限制、受限声明和平台政策由官方核验，market_knowledge 仅供方法参考；本工具集无实时核验，不宣称文案已获平台合规认证。

交付内容诊断、可使用事实、优化草案与未证实占位项，再给验证效果的观察指标。自然位/转化变化并非仅由文案导致，不承诺排名或 Rufus 推荐。
