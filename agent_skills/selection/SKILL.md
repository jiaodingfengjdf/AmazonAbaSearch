# 全流程选品研究

交付能让卖家决定“推进、暂缓、放弃”的研究。无参数从全周期全类目筛选；给出对象就仅对该对象及相关真实词、竞品建立证据，不把用户的假设当结论。

1. 确认数据范围，用 category_analysis/search_keywords 形成需求候选；方向词通过真实检索落地。先明确购买场景与产品边界，再选择少量代表词，不无限扩展。
2. keyword_analysis/keyword_history 验证多期需求和购买承接，google_trends 检验季节与外部关注度。搜索量、购买量、品牌流量和相对指数分别解释。
3. keyword_asins 与 product_history/asin_trends 拆解 1–3 个核心竞品的价带、成熟度、变体、头部份额与稳定性。评论数和评分可用于门槛判断；没有评论正文不能宣称发现用户差评痛点。
4. 对差异化提出可验证的产品假设，而不是仅换包装。做简要单位经济情景，缺采购、运费、费用、退货和广告数据则列变量，不能用缓存毛利率作可实现净利率。并列侵权、合规、季节、库存与进入成本风险。
5. 用主要反证淘汰不适合的选项，给剩余候选最小验证方案：需补的数据、样品与供应链验证、用户验证、价格/转化测试、阶段停止条件。12 次工具预算内优先完成筛选与核心反证，其余明确待做。

输出决策摘要、需求与竞争证据、差异化假设、经济情景、淘汰方案、推进门槛和下一步。评分仅在用户给定维度权重且数据足够时计算并披露，不虚构选品评分。
