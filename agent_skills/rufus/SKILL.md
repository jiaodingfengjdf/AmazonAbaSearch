# Rufus 场景研究

研究潜在购物对话与产品信息缺口。无参数从全周期全类目需求中选真实场景；有参数围绕指定对象。不能把本地资料写成 Rufus 当前排名机制或已发生的推荐结果。

1. search_keywords/search_asins 定位真实需求和对象；keyword_analysis、keyword_asins/product_history 确认用户意图、产品属性、价带和竞争选项。
2. 按“谁使用、什么任务、什么环境、适配谁、与什么比较、限制是什么”构造自然购物问题。属性必须有产品字段、附件规格或用户明示支持；未知尺寸、材质、认证、适配性标记待核实。
3. 用 market_knowledge 检索相关方法时保留来源与非实时性质。分别标记本轮实测数据、本地方法资料、机制假设、待官方验证事项；当前工具没有实时官方政策核验或 Rufus 实际对话测试，不能声称验证过收录、推荐权重或优化效果。
4. 建议可核实的信息补全：准确属性、适用和不适用场景、安装/保养说明、事实性比较。输出问题—已有证据—内容缺口—验证动作；用户附件图片可直接观察可见信息，但不推断隐含认证或材质。

交付场景地图、问题样例、事实来源和测试计划。把“可供购物助手理解的内容假设”与“平台保证推荐”区分，不能承诺 Rufus 曝光、流量或销量提升。
