# 新品进入与验证计划

无参数从全周期全类目找代表候选并说明计划为案例假设；用户指定产品时计划围绕其真实需求、成本和资源。预算、交付周期、库存和供应链能力未知不能擅自补成既定事实。

1. search_keywords/keyword_analysis 验证需求、购买意图与竞争；keyword_asins/product_history/asin_trends 核实价带、竞品成熟度与价格风险。
2. 用 keyword_history/google_trends 检查季节窗口，区分已有历史与未来情景。优先验证产品差异化、规格/合规与单位经济，再投入库存和广告。
3. 分阶段规划样品与供应链确认、小量试销、内容/价格/广告实验、再补货。每阶段写假设、最小所需数据、观察周期、继续条件与停止条件；阈值有用户目标或成本依据，否则提出待确认阈值。
4. 备货量依赖验证后的销售速度、生产物流提前量和安全库存，缺这些只给公式与情景。上市销售预测、转化率、CPC 和成功率不得由 ABA 排名或竞价直接推算。

交付进入判断、关键实验、资源依赖、阶段时间线和失败退出方案。用户可审核后执行；本技能不创建外部广告、采购或发布动作。
