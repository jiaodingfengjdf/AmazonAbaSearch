# 季节性与周期研究

无参数以全周期全类目筛查有周期迹象的需求；有参数仅检索指定方向。当前已采集周跨度短时，不能仅凭几周波动宣布稳定季节规律。

1. keyword_history 获取可用完整历史；keyword_analysis/keyword_snapshots 验证采集周需求、购买与竞争变化。先披露覆盖年数、缺点和频率，避免将不同序列硬拼接。
2. google_trends 对 1–3 个代表词获取 3/5 年完整周序列，保留站点、抓取时间、过期/失败提示。其 0–100 相对指数仅支持趋势形态，零值不等于没有需求；独立请求的指数不能当相同比例的需求量比较。
3. asin_trends 对代表竞品核对价格/销量/BSR 的周期。分辨重复年度峰、短期事件、结构增长和噪声；没有多年度重复就把旺季解释标记为假设。

交付峰谷时间与证据、季节性强弱的依据、准备/补货窗口、提前量情景与错判风险。采购/生产/海运提前量和库存周转未知时只给变量与验证计划，不伪造精确备货数量或销售预测。
