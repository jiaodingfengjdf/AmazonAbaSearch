# 选品与经营风险审查

无参数审视全周期全类目共同经营风险；有参数仅围绕指定产品和真实关联样本审查。将“证据已支持的风险”“需要调查的风险”“资料无法判断”区分，不将未知自动写成违规。

1. 用概览、data_catalog 和必要的 collection_history 查缺周、漏页、字段缺失、重复类目、估计来源与缓存时间。指出这些如何削弱具体结论。
2. keyword_analysis/keyword_history 查需求衰退、购买承接与季节依赖；keyword_asins/asin_trends 查头部固化、价格战、评论门槛、卖家/变体集中。每个风险关联事实和触发条件。
3. 根据商品属性或附件查成本与库存依赖、认证与受限声明、知识产权或品牌依赖。没有官方政策、认证真实性、专利/商标检索能力时列待核验事项；market_knowledge 不是实时法规，不能给法律无风险结论。
4. 对主要机会假设寻找足以否定它的证据，写避免、缓解、接受或暂停的建议。风险优先级用损失影响和证据说明，缺概率就不用伪精确风险分。

交付风险—证据—影响—验证人/资料—暂停条件清单，突出最先影响进入决策的几项。避免泛泛罗列所有可能风险或承诺完成合规审查。
