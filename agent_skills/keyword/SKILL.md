# 关键词深度研究

无参数从全周期全类目真实词中发现代表需求簇；有关键词先用 search_keywords 核实精确词和变体，有 ASIN 先 asin_analysis 反查关联词。保留映射关系，零命中不扩大成无关全盘分析。

1. 从命中词中按购买任务而非字面相似划分核心词、场景词、属性词与品牌词；只纳入真实存在的词，拟议新词另列为假设。
2. keyword_analysis 批量分析 1–5 词；keyword_history 读取完整时间序列，keyword_snapshots 检查份额与各匹配类型竞价。说明同标签最新版、周快照与缓存时间的区别。
3. 结合搜索量、购买量、自然位商品和 TOP3 点击/转化集中度判断需求与竞争；排名改善只能作排名信号。用 keyword_asins 验证词意图对应的产品形态，必要时 google_trends 验证季节。

输出词簇及来源、主词/长尾角色、多期变化、竞争门槛、内容或广告用途与反证。品牌词不自动当通用需求；缺真实广告表现就不预测转化、CPC 或 ACoS。
