# 利润与单位经济研究

无参数从全周期全类目筛查价带与经营风险，不能把缺成本的市场研究写成净利润排行。参数指定产品和成本时逐项保留币种、税口径、单位和来源。

1. search_asins/keyword_asins 找真实价格与形态，product_history/asin_trends 检查价带、价格波动、尺寸重量和销量来源。缓存毛利率只作为供应商字段披露，不作为本卖家可实现净利率。
2. 建立单位经济表：销售净收入减采购、头程/关税、平台佣金、履约、仓储、退货损耗、广告和其他可归属成本。使用用户已给或证据明确费用；亚马逊费率、计费重量和政策时点不可凭记忆写成现行确定值，本工具集不能实时核验官方费用。
3. 未知项用符号变量或明确标注的用户可修改假设，分别做保守/基准/乐观情景；不把假设用 [D] 伪装实测。给售价与成本敏感性、单位贡献利润、盈亏价格，固定费用未知不声称算出净利润。
4. 仅在有广告前贡献利润与收入基数时计算盈亏平衡 ACoS，并说明退货、税费和固定成本边界。竞价区间不等于实际 CPC，不能据此预测广告盈亏。

输出已知/未知费用表、公式、可追溯情景和推进所需报价。证据不足时明确“无法确认利润”，但仍指出影响决策最大的成本变量。
