# 全周期市场复盘

把“市场变化是什么、变化是否可靠、对卖家的决策意味着什么”串成一条证据链。无参数覆盖全部历史与全部类目；有参数仅围绕该方向的真实关键词与商品样本展开，不用全盘结果替代指定对象。

1. 利用 data_overview 与 data_catalog 建立可用周和字段地图；异常跳变或缺周用 collection_history 核对采集页与重复任务。coverage 不完整先界定共同样本。
2. category_analysis 比较需求、购买和集中度结构，结合 dashboard_view 的 weekly/deptScatter 理解图表口径，图表只作导航。将持续变化、季节性、单次采集波动分别解释。
3. search_keywords 分别按 purchases、growth、low_concentration 选代表词；用 keyword_analysis 或 keyword_snapshots 核查同一对象多期份额、需求与自然位变化。必要时 compare_weeks 验证共同样本，不把两期差值写成全周期趋势。
4. 对最重要的 1–3 个变化用 keyword_history、keyword_asins 或 asin_trends 寻找反证：价格下降、头部固化、流量涨而购买不涨、样本覆盖改变。不要为每个类目消耗独立调用。

交付覆盖说明、市场主线、类目分化、代表词证据表、可行动机会与需要观察的反向信号。区分项目样本复盘与亚马逊全站市场结论。
